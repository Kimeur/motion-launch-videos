# Brief: Acme Quest pixel title loop

The showcase for the motion-pixel skill, made with it. Acme Quest is a fictional indie game invented for this demo: it has no live site, so the brief below is the only source, and the film says so on screen. The domain is the reserved `example.com`.

## Deliverable

| | |
|---|---|
| Product | Acme Quest, a fictional indie game (no live site: demo copy) |
| Style | pixel art (motion-pixel) |
| Format | 1080 x 1080 (1:1), drawn on a 180 x 180 logical canvas at x6 |
| Duration | 10 s, cycle loop (600 frames) |
| Frame rate | 60 fps |
| Tempo grid | 120 BPM: a beat is 0.5 s, a bar is 2 s, a 16th is 0.125 s |
